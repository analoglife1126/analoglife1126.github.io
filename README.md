# 模拟人生（analoglife）的技术主页

网站：https://analoglife1126.github.io/

清华大学电子信息硕士在读，关注数字 IC、处理器与嵌入式硬件设计。

## 页面内容

- SHA-256 加速 IP 的设计、验证和架构比较
- 单周期处理器与 ZYNQ 软硬协同验证
- 嵌入式板卡研发经历、教育背景和联系方式

## 维护

页面为静态 HTML、CSS 与 JavaScript，支持桌面和手机。修改 `index.html` 更新内容，修改 `assets/style.css` 调整样式，替换 `assets/analoglife-profile.pdf` 更新简历。

通过 GitHub Pages 从默认分支的根目录发布；`.nojekyll` 用于直接提供静态文件。

SHA-256 比较条件为 TSMC 90 nm、200 MHz。吞吐率为理想输入条件下的核内稳态上限；面积为布局前映射单元面积。

校徽矢量的来源与许可见 `assets/THIRD_PARTY_NOTICES.md` 和 `assets/THU-CREST-LICENSE.txt`。
