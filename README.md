# analoglife 的学习与设计记录

网站：https://analoglife1126.github.io/

关注数字 IC、处理器与硬件系统设计，以简介、学习笔记和项目实践为主，持续记录项目实践、设计取舍与验证结果。

## 页面内容

- 简短介绍与记录方向
- 从现有项目提炼的学习笔记
- SHA-256、单周期处理器与板级硬件的设计记录
- 独立项目页：主要工作、设计取舍、结果与技术标签

页面采用窄版单栏、纯白背景、黑色标题与灰色正文，支持浅色和深色外观。笔记和项目技术细节可以点击展开，内容不依赖外部服务。导航对应独立页面，项目页以条目形式整理实践经历。

## 维护

页面为静态 HTML、CSS 与 JavaScript，支持桌面与手机。`index.html` 为首页，`notes.html`、`projects.html` 和 `about.html` 分别为笔记、项目和关于页面。修改对应页面更新内容，修改 `assets/style.css` 调整样式。

通过 GitHub Pages 从默认分支的根目录发布；`.nojekyll` 用于直接提供静态文件。

站点仅展示昵称和技术内容，不提供简历下载、邮箱、院校、任职单位或个人履历。请勿将这些信息重新添加到页面、元数据或静态资源中。

SHA-256 比较条件为 TSMC 90 nm、200 MHz。吞吐率为理想输入条件下的核内稳态上限；面积为布局前映射单元面积。
